The Copado org where user stories are created

Connect opens the org's login page in a tab and adopts the session you create there. Your password never reaches this extension, and nothing is installed or configured in the target org.

Copado org

The generic login page resolves to whichever org the browser is already signed in to, and the extension cannot tell that apart from the one you meant. Use the org's My Domain URL so a wrong session is refused.

Copado AI

Copado AI is not a Salesforce org and has no session to borrow. Create a Personal Access Key in the Robotic Testing app under User settings & preferences, and take the organization id from the API URL — every endpoint is scoped to one.

How connecting works

Prefer a My Domain URL over the generic login pages. If the browser already holds a session for a different org, login.salesforce.com can land on that one instead; a My Domain URL always resolves to the org you meant. The connection shows which org and user it actually captured so a wrong target is visible immediately.

  • One org is connected at a time. Connecting another releases the previous one, but only once the new login succeeds.
  • SSO and MFA work normally — Salesforce runs the login, not this extension.
  • A session is not a refresh token: it ends on logout and on the org's session timeout, and you reconnect when it does.
  • Disconnect only drops the extension's copy. Your browser login stays active.
